# A floor, not a pin. YouTube breaks extractors every few months and a fix
# usually ships within days, so the image also upgrades yt-dlp at boot unless
# YTDLP_AUTO_UPDATE=false — see docker/entrypoint.sh.
#
# The [default] extra is what pulls in yt-dlp-ejs, the challenge-solver scripts
# the JavaScript runtime executes. Without it they are fetched from GitHub on
# first use (YTDLP_REMOTE_COMPONENTS), which turns every boot into a network
# dependency on a host that may well have none.
yt-dlp[default]>=2026.7.4
mutagen==1.47.0

# The TLS fingerprint YouTube is willing to serve. yt-dlp can impersonate a
# real browser handshake, but only through curl_cffi — and the [default] extra
# above does *not* include it, so without this line yt-dlp reports zero
# impersonation targets and every request goes out looking like a python
# script. On a home connection that is usually tolerated; from a VPN or a
# datacenter it is a large part of why the media fetch answers 403 when the
# search on the same connection did not. See YTDLP_IMPERSONATE in .env.example.
curl_cffi>=0.7.0
